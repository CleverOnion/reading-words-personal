# 学习画像 / 记忆观测站

入口：顶部「学习画像」。使用当前账号真实作答记录，只读聚合，不修改历史或词库。

- 7 / 30 / 90 天窗口包含今天，以北京时间分日；与前一个同长窗口比较自评没忘记占比。没有作答时显示未知，而非 0%。
- 阅读星图展示 60 篇阅读的累计词条覆盖和连续 3 次没忘记的巩固状态。点选可查看完成轮数、近期作答，再进入练习或原文。
- 84 天热力图独立于窗口筛选，可点日期查看作答、新词、忘记次数和用时。连续天数允许今天尚未练习，历史最长保留。
- 六个四小时时段展示实际学习节奏。用时累加每次作答，单次限制 0–300 秒，不表示在线时长。
- 薄弱词按窗口内忘记次数排序，仅保留目前待巩固词；可直接复习这组词。
- 重新想起展示曾经忘记、目前连续 3 次没忘记的词；后续再忘记则回到待巩固。
- 里程碑基于实际记录；初次练习按词条第一次作答日期计算，同一词条反复练不重复计数。不同阅读中的同形词按各自词条计数。

接口：`GET /api/statistics?days=30`，鉴权与现有学习接口相同，响应禁止缓存。

检查：`node --test scripts/statistics.test.ts`；`node scripts/verify-statistics.mjs [baseURL]` 为只读接口核验，可用于生产环境。
