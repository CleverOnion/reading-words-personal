# 回看与自评背词

练习页的“回看已背单词”默认打开本轮最近一次已提交的词，支持前后翻页；展示词库释义与当时作答，不能修改答案。窗口打开期间禁用底层答题快捷键，扣除回看用时；关闭回到原题与原反馈。

会话接口返回已保存的 answers 数组（position、wordId、choice、correct），不包含未作答词的预览。当前题保存成功后本地追加，重试按 position 去重。刷新后由服务器还原。

所有新练习（包括错词重练）统一使用 recall，不再提供背词方式选择器。初始卡片只显示单词；点击卡片或按空格 / Enter 展开词库释义，然后选择“忘记了”或“没忘记”。忘记了沿用现有错词与复习安排。自评记录标注“自评”和“未忘记率”，不记为客观测验正确率。

sessions.study_format 持久化 choice/recall，旧会话迁移默认 choice。本次按用户要求清空旧会话，书架只续接 recall 会话。前端不再读取或保存背词方式偏好，服务器以会话已保存的方式为准。导出保留 study_format，旧备份导入默认 choice。

部署先应用 drizzle/0003 数据库迁移，再发布。scripts/verify-practice-modes.mjs 仅在本机隔离数据库执行有写入的集成验证。

自评快捷键：展开释义后 1=忘记了，2=没忘记。保存成功自动进入下一词，最后一词自动进入小结；请求未确认成功时留在当前词以便重试。长按重复事件、组合键、输入框、回看/原文弹窗内不触发自评。
