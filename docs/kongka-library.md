# 空卡阅读词库与全新开始

根据用户 2026-09-23 的最终要求，本次发布替换全部活动词库，仅保留 2010—2024 英语一阅读理解 Part A 的 Text 1—4，共 60 篇、3,367 个词条（其中选项词 577 个）。2025—2026 暂不上架。原文与译文仍对应这 60 篇。

来源为用户提供的《空卡真题核心词（英语一）免费分享.pdf》。扫描件在本机 OCR，按表格题型标题划分，不按整页盲目导入；完形、新题型、翻译等词表均排除。段落与选项保留分类，page 为 PDF 文件的物理页码，不是书内印刷页码。全部阅读相关页已逐图对照，403 项校正保存在 kongka-corrections.json；统计见 kongka-import-report.json。原书自身疑似错字不擅自改成别的来源。

唯一释义缺失：2024 Text 3 选项词 dispute，原书只列音标。保留词条并提供明确标注“补充释义，原书未注”的基本释义；其余释义以该 PDF 为准。

提取步骤：scripts/ocr-kongka.py（本地缓存，RapidOCR）、parse-kongka.py（表格行）、build-kongka-candidates.py（题型边界与候选）、import-kongka.py（应用人工校正与校验）。缓存含原页图，不上传网站。

用户随后明确要求清空旧记录、错词与收藏，全部以新词库为准。因此不迁移旧词 ID。部署时使用仅限定当前个人账号的 SQL 清理 attempts、saved_words、sessions，并验证新站为空；发布前的私有备份仅用于部署恢复，不展示在网站中。2025—2026 源文件仍留在开发项目，活动词库和已发布原文不含这两年。

新练习默认且只接受 recall：先显示单词，点击卡片或空格/Enter 后展开释义，再选“忘记了／没忘记”。每题保存，可退出续练；回看已提交的词不会改变答案或计入作答时间。
