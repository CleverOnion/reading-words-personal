# AI 母语语感

入口：网站右上角「AI 设置」。填写公开 HTTPS Base URL、模型 ID 和 API Key，支持兼容 OpenAI Chat Completions 的文本服务。地址可填 `/v1` 或完整 `/chat/completions`；不自动猜测提供商特有路径。

先保存配置并试生成一个词，再点击「开始全量生成」。同一英文词头跨篇共享解释，提示词包含最多六条不同词库释义。生成核心直觉、语体、自然搭配、误用辨析、双语例句；作为 AI 说明标注，不替换用户词库释义。

`ai_settings` 保存账号配置，API Key 用 AES-GCM 加密、绑定用户 ID，密钥派生自服务端 `PRIVATE_SESSION_SECRET`。GET 仅返回 `hasKey`；更换地址必须重新填 Key。更换配置自动暂停现有任务，正在运行的少量请求仍会完成并标明原模型。轮换 `PRIVATE_SESSION_SECRET` 后需重新保存 API Key。

`ai_notes` 按用户和规范化词头存储内容与任务状态。读取不触发付费请求。单词卡揭晓后显示语感面板，可手动重新生成，成功才替换旧内容。失败保留旧版；浏览器不会等待 AI 请求才能继续背词。

`ai_jobs` 是持久化后台队列。部署脚本在现有 Worker 增加每分钟 Cron 和 `scheduled` 处理器；无运行任务时只查询状态，不发模型请求。每次最多处理九个词、并发三，单请求 60 秒超时。任务锁五分钟、单词锁两分钟，异常退出后可恢复。401/403/额度不足等服务错误，以及整组三个失败会暂停任务，避免把全库重复发给有问题的服务。开始/继续只补缺失项并重试失败项，不覆盖已成功项。

Cron 首次生效可能延迟最多约 15 分钟：[Cloudflare 文档](https://developers.cloudflare.com/workers/configuration/cron-triggers/)。全部生成通常需数小时，取决于响应时间及限流。用户选定模型后才能实际执行；没有配置时不生成、也不提供伪造的预生成内容。

部署先执行 `0005_native_ai.sql`，再发布 Worker。包含 AI 内容的学习备份不包含 Key 或服务配置；导入工具兼容没有 AI 内容的旧备份。

验证：格式与加密单元测试、实际 API 的 SQLite/D1 适配集成测试（模拟服务，无收费请求）、持久化队列与并发锁、失败保留旧结果、暂停与恢复、桌面和手机界面检查。尚未配置真实提供商时不能声称完成真实模型联调或全量生成。
